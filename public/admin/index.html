    🏅 Points de récompense saisonniers

    Mode d'attribution

    Simulation : les points de fin de saison sont calculés et montrés aux joueurs, jamais crédités. Réel : les saisons terminées après l'activation sont créditées au portefeuille (aucun crédit rétroactif). Activer = valider le barème en vigueur.

    Barème (JSON, versionné)

    Catégories exclusives, évaluées dans l'ordre : rankMax (rang ≤ N) ou percentMax (top p %, arrondi au-dessus), minEligible (catégorie ignorée sous ce nombre d'éligibles), sans condition = autres participants. Options : tiesShareTier, leagueBonusPctPerLevel, maxRiskLevel (null = aucune exclusion anti-bot).

    🧱 Catalogue de blocs

    Contenu du jeu (minerais, pierres, coffres, gemmes) — distinct des cadeaux réels (onglets Concours / Boutique). Les modifications vont dans un brouillon : rien ne change pour les joueurs avant « Publier ». Un bloc déjà publié ne se supprime pas, il se désactive. Aucune profondeur maximale : un bloc apparaît dès X m puis à toutes les profondeurs suivantes.

    ✨ Création assistée par IA

    Décrivez un bloc, un minerai ou un coffre : l'IA propose les noms FR/EN/NL, la catégorie, les paramètres et une icône dans le style validé. Corrigez chaque langue, régénérez une partie, vérifiez l'impact, puis « Ajouter au brouillon ». Rien n'est publié automatiquement.

              🎨 Atelier d'icônes

              Toutes les icônes du jeu au même endroit : blocs (minerais, pierres, coffres, gemmes), objets de collection et reliques, pictogrammes d'interface. Style commun : celui des icônes v1 validées (la pierre validée est jointe à chaque génération). Générez 1 à 3 variantes (une icône ou un lot), ou téléversez une image ; chaque image passe les contrôles (fond transparent réel, marges 12 %, recadrage, lisibilité sur fond sombre). « Appliquer » place l'icône dans le brouillon du catalogue concerné : rien ne change pour les joueurs avant la publication dans l'onglet 🧱 Blocs ou 📿 Collections. Une icône validée n'est jamais remplacée sans votre accord explicite.
